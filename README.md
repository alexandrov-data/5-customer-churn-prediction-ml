# Прогнозирование оттока клиентов фитнес-клуба

## О проекте
В проекте анализируются данные клиентов сети фитнес-клубов, чтобы выявить факторы оттока и помочь бизнесу удерживать клиентов.

Цель — определить, какие признаки связаны с уходом клиентов, построить модель прогнозирования оттока и выделить клиентские сегменты с разным уровнем риска.

## Бизнес-задача
Для фитнес-клуба важно заранее понимать, какие клиенты с высокой вероятностью перестанут посещать занятия.

Анализ помогает ответить на ключевые бизнес-вопросы:
- какие клиенты наиболее склонны к оттоку;
- какие признаки сильнее всего связаны с уходом;
- как выделить группы клиентов для более точечной работы по удержанию.

## Задачи
- подготовить и изучить исходные данные;
- провести исследовательский анализ данных;
- сравнить признаки ушедших и оставшихся клиентов;
- построить модель прогнозирования оттока;
- оценить качество моделей по основным метрикам;
- провести кластеризацию клиентов;
- сформулировать рекомендации по удержанию клиентов.
