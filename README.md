# Прогнозирование оттока клиентов фитнес-клуба

## О проекте
В проекте анализируются данные клиентов сети фитнес-клубов, чтобы выявить признаки оттока и помочь бизнесу удерживать клиентов.  
Цель — понять, какие клиенты склонны к уходу, какие факторы сильнее всего связаны с оттоком, и как на основе данных выстроить более эффективную стратегию удержания.

## Задачи
- подготовить и изучить данные о клиентах фитнес-клуба
- провести исследовательский анализ и выявить различия между ушедшими и оставшимися клиентами
- определить признаки, связанные с повышенным риском оттока
- построить модели машинного обучения для прогнозирования ухода клиентов
- провести кластеризацию клиентской базы
- сформулировать выводы и базовые рекомендации для бизнеса

## Использованные инструменты
- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scikit-learn
- scipy
- Jupyter Notebook

## Ключевые этапы работы
1. Загрузка и предобработка данных  
2. Исследовательский анализ данных (EDA)  
3. Сравнение профиля ушедших и оставшихся клиентов  
4. Анализ корреляций признаков  
5. Построение моделей прогнозирования оттока  
6. Оценка качества моделей по метрикам accuracy, precision, recall и F1-score  
7. Кластеризация клиентов и анализ сегментов  
8. Интерпретация результатов и подготовка рекомендаций

## Результат
В результате проекта были выявлены признаки клиентов с повышенным риском оттока: как правило, это клиенты с коротким сроком контракта, меньшей вовлечённостью, более редким посещением клуба и низкой активностью в дополнительных услугах.  

Были построены две модели прогнозирования оттока — логистическая регрессия и случайный лес. Обе показали близкое качество, при этом случайный лес дал немного лучшие результаты по ключевым метрикам. Также была проведена кластеризация клиентов, которая позволила выделить несколько сегментов с разным уровнем риска оттока.  

Практическая ценность проекта состоит в том, что его результаты могут использоваться для снижения оттока клиентов: точечной работы с группами риска, развития программ лояльности, продвижения долгосрочных абонементов и более адресных маркетинговых предложений.
